## Firestore Collections

### `menu_items/{itemId}`

| Field | Type | Notes |
|-------|------|-------|
| `id` | String | Document ID (auto-generated) |
| `name` | String | Display name |
| `description` | String | Full description (also searched client-side — FR-002) |
| `inStorePrice` | Number | Price in dollars (2 decimal places) |
| `appPrice` | Number? | `nil` means use `inStorePrice` in app |
| `isAppOnly` | Boolean | True if item is available in-app only |
| `allergens` | Array\<String\> | e.g., `["gluten", "dairy"]` |
| `pointValue` | Number | Points earned per item (integer, ≥ 0) |
| `category` | String | `"Coffee"` \| `"Food"` \| `"Drinks"` \| `"Pastry"` |
| `isAvailable` | Boolean | Staff toggle; false hides item from active orders |
| `createdAt` | Timestamp | |
| `updatedAt` | Timestamp | Used to detect staleness in cache refresh |

**Access**: Public read. Admin write only (café owner via console).

| `expiresAt` | Timestamp? | Set when status transitions to `"ready"`; used by scheduled expiry Cloud Function (FR-013) |
| `createdAt` | Timestamp | |

**`OrderItem` sub-object**:

| Field | Type | Notes |
|-------|------|-------|
| `menuItemId` | String | |
| `name` | String | Denormalized (menu item names can change; order is a snapshot) |
| `size` | String? | `"Small"` \| `"Medium"` \| `"Large"` — nil if item has no size |
| `specialInstructions` | String? | Free-text (FR-003) |

## Swift Domain Models

```swift
// MARK: - Auth

struct AuthUser {
    let id: String
    let email: String
    let displayName: String
    let role: UserRole
}

enum UserRole {
    case customer
    case worker
    case owner
}

// MARK: - Menu

struct MenuItem: Identifiable, Codable {
    let id: String
    let name: String
    let description: String
    let inStorePrice: Double
    let appPrice: Double?          // nil → use inStorePrice in app
    let isAppOnly: Bool
    let allergens: [String]
    let pointValue: Int
    let category: MenuCategory
    let isAvailable: Bool
}

enum MenuCategory: String, CaseIterable, Codable {
    case coffee  = "Coffee"
    case food    = "Food"
    case drinks  = "Drinks"
    case pastry  = "Pastry"
}

extension MenuItem {
    var effectiveAppPrice: Double { appPrice ?? inStorePrice }
}

// MARK: - Orders

struct Order: Identifiable {
    let id: String
    let customerId: String
    let customerName: String
    var items: [OrderItem]
    let totalAmount: Double
    let totalPointsEarned: Int
    var status: OrderStatus
    let requestedReadyTime: Date
    let createdAt: Date
    var statusTimestamps: OrderStatusTimestamps
}

struct OrderItem {
    let menuItemId: String
    let name: String
    let size: String?
    let specialInstructions: String?
    let pointValue: Int
    let price: Double
    var isCheckedOff: Bool
}

enum OrderStatus: String, Codable {
    case pending
    case accepted
    case inProcess    = "in_process"
    case ready
    case completed
    case expired
}

struct OrderStatusTimestamps {
    let pending: Date
    let accepted: Date?
    let inProcess: Date?
    let ready: Date?
    let completed: Date?
    let expired: Date?
}

// MARK: - Loyalty

struct LoyaltyAccount {
    let customerId: String
    let membershipBarcode: String  // UUID v4 string; displayed as QR code
    let totalPoints: Int
    let orderCount: Int
}

struct Reward: Identifiable {
    let id: String
    let customerId: String
    let type: RewardType
    let monetaryValue: Double
    let claimDate: Date
    let expiryDate: Date           // claimDate + 30 days (FR-009)
    var redemptionStatus: RedemptionStatus
    let redeemedAt: Date?
}

enum RewardType: String, Codable {
    case freeCoffee = "free_coffee"
}

enum RedemptionStatus: String, Codable {
    case unredeemed
    case pendingRedemption = "pending_redemption"
    case redeemed
}

extension Reward {
    var isActive: Bool {
        redemptionStatus == .unredeemed && expiryDate > Date()
    }
}

// MARK: - Cafe Config

struct CafeConfig {
    let openTime: String               // "HH:mm"
    let closeTime: String              // "HH:mm"
    let orderCutoffMinutes: Int        // default 15
    let orderTimeoutMinutes: Int       // default 120
    let timezone: TimeZone
}

// MARK: - Payment (domain types — no Square SDK types)

struct PaymentResult {
    let paymentReference: String       // Stripe PaymentIntent ID (opaque)
    let status: PaymentStatus
}

enum PaymentStatus {
    case succeeded
    case failed(reason: String)
    case cancelled
}
```

## State Machines

### Order Status

```
pending → accepted → in_process → ready → completed
                                        ↘ expired   (auto, via Cloud Function if not collected within timeout)
```

Transitions:
- `pending → accepted`: Worker taps "Accept" (FR-010, US3 scenario 3)
- `accepted → in_process`: Worker begins checking off items (implicit on first check-off)
- `in_process → ready`: All `items[].isCheckedOff == true` (FR-012, US3 scenario 5)
- `ready → completed`: Worker marks order collected (manual confirmation)
- `ready → expired`: Cloud Function detects `expiresAt < now` (FR-013, US3 scenario 6)

### Reward Redemption Status

```
unredeemed → pending_redemption → redeemed
```

Transitions:
- `unredeemed → pending_redemption`: Customer taps "Redeem" in-app (FR-021)
- `pending_redemption → redeemed`: Staff manually confirms (or via Firebase console for MVP)

## Firestore Security Rules (Summary)

```
menu_items:      public read; admin write (owner role)
customers:       read/write by matching uid
loyalty_accounts: read by matching uid; write by Cloud Functions (server token) only
point_transactions: read by matching customerId; write by Cloud Functions only
rewards:         read by matching customerId; write redemptionStatus/redeemedAt by matching customerId;
                 full write by Cloud Functions
orders:          create by authenticated customer; read by matching customerId + staff;
                 update status/isCheckedOff by staff + Cloud Functions; no customer update post-creation
cafe_config:     public read; admin write
staff:           read/write by matching uid; no self-write to role field
```
